Módulo 7: Compilación de Frontend

Gestión de Dependencias JavaScript

Laravel no es solo PHP. Para tener diseños modernos, utiliza herramientas del ecosistema Node.js. Esta fase descarga y compila los archivos CSS y JavaScript necesarios para que tu web se vea profesional.

Node Package Manager

> _

1. npm install

Así como Composer descarga librerías de PHP, NPM descarga librerías de JavaScript.

¿Qué descarga exactamente?

  • Vite: El compilador ultra-rápido que usa Laravel.
  • Axios: Para hacer peticiones HTTP asíncronas (AJAX).
  • Tailwind CSS: (Si lo elegiste) El framework de diseño.
  • Alpine.js / Vue / React: Librerías de interactividad.

Crea la carpeta node_modules (que suele ser muy pesada).

2. npm run build

Los navegadores web no entienden archivos modernos complejos (como Sass, TypeScript o módulos avanzados). Necesitamos "traducirlos".

El proceso de compilación (Vite):

  1. Toma tus archivos "crudos" de la carpeta /resources.
  2. Los comprime y minifica (quita espacios para que pesen menos).
  3. Genera archivos .css y .js listos para producción en la carpeta /public.

Diferencia Clave: Backend vs Frontend

Composer (PHP) NPM (Node.js)
Gestiona la lógica del servidor (Laravel, conexiones BD). Gestiona la parte visual (CSS, JavaScript, Interactividad).
Archivo: composer.json Archivo: package.json
Carpeta: /vendor Carpeta: /node_modules

Recomendación
