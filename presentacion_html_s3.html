Guía Práctica de Controladores en Laravel

Aprende a crear y utilizar controladores en Laravel con ejemplos claros y ejercicios prácticos

1. ¿Qué es un controlador?

Un controlador en Laravel es una clase PHP que se encarga de recibir las peticiones HTTP, procesar la lógica necesaria y devolver una respuesta. Su objetivo principal es separar la lógica de la aplicación de las rutas, logrando un código más limpio y mantenible.

Ubicación de controladores: app/Http/Controllers

Ventajas de usar controladores

Código organizado

Mantén tu código limpio, estructurado y fácil de mantener separando la lógica de las rutas.

Separación de responsabilidades

Cada componente tiene una función específica, siguiendo el principio de responsabilidad única.

Reutilización de lógica

Puedes reutilizar métodos de controladores en diferentes rutas, evitando duplicación de código.

Flujo MVC en Laravel

Rutas

Reciben la petición HTTP

Controlador

Procesa la lógica

Vista/Respuesta

Devuelve la respuesta al usuario

2. Crear un controlador básico

Para crear un controlador en Laravel, utilizamos el comando Artisan:

php artisan make:controller UserController

Este comando genera el archivo UserController.php en la carpeta app/Http/Controllers.

Ejemplo de controlador básico

<?php

namespace App\Http\Controllers;

use Illuminate\Routing\Controller;

class UserController extends Controller
{
    /**
     * Método para saludar al usuario
     * @return string
     */
    public function saludo(): string
    {
        return "Hola desde el controlador";
    }
}

Ruta asociada en routes/web.php

<?php

use App\Http\Controllers\UserController;
use Illuminate\Support\Facades\Route;

// Ruta básica que apunta al método saludo() del controlador
Route::get('/saludo', [UserController::class, 'saludo']);

Resultado: Al acceder a http://tudominio.com/saludo se mostrará: "Hola desde el controlador"

3. Controladores con parámetros

Los controladores pueden recibir parámetros directamente desde la URL, lo que permite crear rutas dinámicas y flexibles.

Controlador con parámetro

<?php

namespace App\Http\Controllers;

class UserController extends Controller
{
    /**
     * Mostrar perfil de usuario
     * @param string $nombre
     * @return string
     */
    public function perfil(string $nombre): string
    {
        return "Perfil del usuario: " . $nombre;
    }
}

Ruta con parámetro dinámico

<?php

use App\Http\Controllers\UserController;
use Illuminate\Support\Facades\Route;

// Ruta con parámetro {nombre}
Route::get('/perfil/{nombre}', [UserController::class, 'perfil']);

// También se pueden usar múltiples parámetros
Route::get('/usuario/{id}/{nombre}', [UserController::class, 'mostrar']);

4. Uso de Request para recibir datos

Laravel utiliza la clase Request para manejar los datos enviados por formularios o peticiones HTTP.

Controlador que procesa datos POST

<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class UserController extends Controller
{
    /**
     * Guardar datos de usuario
     * @param Request $request
     * @return string
     */
    public function guardar(Request $request): string
    {
        // Obtener datos del formulario
        $nombre = $request->input('nombre');
        $correo = $request->input('correo');

        // También se puede usar:
        // $nombre = $request->nombre;
        // $correo = $request->correo;

        return "Nombre: $nombre | Correo: $correo";
    }
}

Ruta para método POST

<?php

use App\Http\Controllers\UserController;
use Illuminate\Support\Facades\Route;

Route::post('/guardar-usuario', [UserController::class, 'guardar']);

Formulario HTML en Blade

<!-- resources/views/formulario.blade.php -->
<form method="POST" action="/guardar-usuario">
    @csrf <!-- Token de seguridad -->

    <div class="mb-4">
        <label for="nombre" class="block text-gray-700">Nombre</label>
        <input type="text" name="nombre" id="nombre" class="border rounded p-2 w-full" required>
    </div>

    <div class="mb-4">
        <label for="correo" class="block text-gray-700">Correo</label>
        <input type="email" name="correo" id="correo" class="border rounded p-2 w-full" required>
    </div>

    <button type="submit" class="bg-blue-500 text-white px-4 py-2 rounded">
        Enviar
    </button>
</form>

Importante: Protección CSRF
El uso de @csrf en formularios Laravel es esencial para protección contra ataques CSRF (Cross-Site Request Forgery). Laravel verifica automáticamente este token en cada petición POST.

5. Controladores CRUD (Resource)

Laravel permite crear controladores que incluyen automáticamente las operaciones CRUD (Create, Read, Update, Delete) con un solo comando.

php artisan make:controller ProductController --resource

Estructura generada automáticamente

MÉTODO ACCIÓN RUTA VERBO HTTP
index() Listar registros /Productos GET
create() Mostrar formulario creación /Productos/create GET
store() Guardar nuevo registro /Productos POST
show($id) Mostrar un registro /Productos/{id} GET
edit($id) Mostrar formulario edición /Productos/{id}/edit GET
update($id) Actualizar registro /Productos/{id} PUT/PATCH
destroy($id) Eliminar registro /Productos/{id} DELETE

Ejemplo de controlador resource

<?php

namespace App\Http\Controllers;

use App\Models\Producto;

class ProductController extends Controller
{
    public function index()
    {
        $productos = Producto::all();
        return view('productos.index', compact('productos'));
    }

    public function show($id)
    {
        $producto = Producto::findOrFail($id);
        return view('productos.show', compact('producto'));
    }
}

Ruta resource (todas las rutas)

<?php

use App\Http\Controllers\ProductController;
use Illuminate\Support\Facades\Route;

// Una sola línea para todas las rutas CRUD
Route::resource('productos', ProductController::class);

// También se pueden excluir métodos
Route::resource('productos', ProductController::class)->except([
    'create', 'edit'
]);

6. Controladores Invokable (Single Action)

Un controlador invokable en Laravel es un controlador que contiene un único método llamado __invoke(). Este tipo de controlador se utiliza cuando una ruta necesita ejecutar una sola acción específica, promoviendo un diseño más claro y enfocado.

Responsabilidad única

Cada controlador tiene una única responsabilidad, siguiendo el principio de responsabilidad única.

Código más limpio

Elimina métodos innecesarios y mantiene el controlador enfocado en una sola tarea.

Ideal para acciones simples

Perfecto para páginas de contacto, páginas de inicio, confirmaciones, etc.

Ejemplo de controlador invokable

<?php

namespace App\Http\Controllers;

class MostrarPerfil extends Controller
{
    /**
     * Mostrar perfil de usuario
     *
     * @param string $nombre
     * @return string
     */
    public function __invoke(string $nombre): string
    {
        return "Mostrando perfil de: $nombre";
    }
}

Rutas simplificadas

<?php

// Ruta tradicional (necesita especificar método)
Route::get('/perfil/{nombre}', [PerfilController::class, 'mostrar']);

// Ruta para controlador invokable (más limpia)
Route::get('/perfil/{nombre}', MostrarPerfil::class);
php artisan make:controller ContactController --invokable

7. Ejercicios prácticos

Pon en práctica lo aprendido con estos ejercicios. Cada ejercicio incluye el enunciado y la solución completa.

Ejercicio 1: Controlador básico

Enunciado: Crea un controlador llamado SaludoController con un método bienvenida() que muestre: "Bienvenido al sistema"

Solución:

<?php

namespace App\Http\Controllers;

class SaludoController extends Controller
{
    public function bienvenida()
    {
        return "Bienvenido al sistema";
    }
}

Ruta en routes/web.php:

Route::get('/bienvenida', [SaludoController::class, 'bienvenida']);

Ejercicio 2: Controlador con parámetro

Enunciado: Crea un controlador ProductoController con un método detalle($id) que muestre: "Detalle del producto ID: X"

Solución:

<?php

namespace App\Http\Controllers;

class ProductoController extends Controller
{
    public function detalle($id)
    {
        return "Detalle del producto ID: $id";
    }
}

Ruta en routes/web.php:

Route::get('/producto/{id}', [ProductoController::class, 'detalle']);

Ejercicio 3: Controlador con formulario

Enunciado: Crea un formulario que envíe nombre y edad a un controlador y muestre: "Nombre: Juan | Edad: 20"

Solución:

<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class FormularioController extends Controller
{
    public function mostrarFormulario()
    {
        return view('formulario');
    }

    public function procesar(Request $request)
    {
        $nombre = $request->input('nombre');
        $edad = $request->input('edad');
        return "Nombre: $nombre | Edad: $edad";
    }
}

Rutas en routes/web.php:

Route::get('/formulario', [FormularioController::class, 'mostrarFormulario']);
Route::post('/procesar', [FormularioController::class, 'procesar']);

Ejercicio 5: Controlador Invokable

Enunciado: Crea un controlador invokable llamado ContactController que muestre información de contacto cuando se acceda a la ruta /contacto.

Solución:

<?php

namespace App\Http\Controllers;

class ContactController extends Controller
{
    public function __invoke()
    {
        $contacto = [
            'email' => 'contacto@empresa.com',
            'telefono' => '+34 123 456 789',
            'direccion' => 'Calle Principal, 123'
        ];

        return view('contacto', compact('contacto'));
    }
}
php artisan make:controller ContactController --invokable

Ruta en routes/web.php:

Route::get('/contacto', ContactController::class);
