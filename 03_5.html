Módulo Avanzado: Drivers y Extensiones PDO

Compatibilidad de Motores de Base de Datos

El instalador de Laravel detecta automáticamente las extensiones PHP habilitadas en el entorno. A continuación, se detalla el significado de las advertencias de "Missing PDO extension" y el procedimiento técnico para su resolución en entornos Windows/Linux.

System Check
Which database will your application use? [MySQL]:
  • ○ [sqlite ] SQLite
  • ● [mysql ] MySQL
  • ○ [mariadb ] MariaDB
  • ○ [pgsql ] PostgreSQL
    (Missing PDO extension)
  • ○ [sqlsrv ] SQL Server
    (Missing PDO extension)

Diagnóstico: ¿Qué significa "Missing PDO extension"?

PHP actúa como intermediario entre la aplicación (Laravel) y la base de datos. Para comunicarse, PHP requiere un "Driver" específico llamado extensión PDO (PHP Data Objects).

El mensaje indica que el intérprete de PHP instalado en el sistema no tiene activada o instalada la librería dinámica (.dll en Windows o .so en Linux) necesaria para comunicarse con PostgreSQL o SQL Server.

Caso A: Habilitar PostgreSQL

En la mayoría de distribuciones (XAMPP, Laragon, PHP Standalone), el driver de PostgreSQL ya viene incluido en la carpeta /ext, pero se encuentra comentado (desactivado) por defecto.

1

Localizar php.ini

Ubique el archivo de configuración principal de PHP.

2

Descomentar Extensiones

Elimine el punto y coma (;) inicial en las siguientes líneas:

; extension=pdo_mysql
extension=pdo_pgsql <-- Habilitar
extension=pgsql <-- Habilitar
3

Reiniciar Servicios

Reinicie Apache/Nginx o la terminal para aplicar cambios.

Caso B: SQL Server (Complejo)

PHP no incluye nativamente los drivers para Microsoft SQL Server. Es necesario descargar los binarios manualmente e instalarlos.

1

Descargar DLLs

Descargue "Microsoft Drivers for PHP for SQL Server" desde el sitio oficial de Microsoft. Asegúrese de que coincida con su versión de PHP (Thread Safe).

2

Instalación en /ext

Copie los archivos php_sqlsrv.dll y php_pdo_sqlsrv.dll a la carpeta ext de su instalación de PHP.

3

Editar php.ini

Agregue manualmente las siguientes líneas al final del archivo:

extension=php_sqlsrv.dll
extension=php_pdo_sqlsrv.dll
