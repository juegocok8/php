Instalación y Configuración

Aprende a configurar tu entorno de desarrollo utilizando el instalador global de Laravel para un flujo de trabajo más rápido y eficiente.

1 El Instalador de Laravel

Para crear nuevos proyectos de Laravel rápidamente, recomendamos instalar el instalador global mediante Composer. Este paquete instala un binario en tu sistema que te permite acceder al comando laravel desde cualquier carpeta.

Terminal
$ composer global require laravel/installer

¿Qué hace este comando?

  • Global: Instala la herramienta a nivel de sistema operativo, no solo en la carpeta actual.
  • Require: Ordena a Composer descargar el paquete.
  • Laravel/Installer: Es una herramienta ligera CLI (Línea de Comandos) que actúa como asistente.

¿Por qué usar el instalador?

Método Tradicional (Largo)
Difícil de recordar
composer create-project laravel/laravel mi-proyecto
Recomendado
Con el Instalador
$ laravel new mi-app

Mucho más corto, intuitivo y rápido de escribir.

Siguientes Pasos

Una vez instalado el proyecto, utiliza Artisan para gestionar tu aplicación:

php artisan serve

Inicia el servidor de desarrollo local.

php artisan migrate

Ejecuta las migraciones de base de datos pendientes.
