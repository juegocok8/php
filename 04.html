Pasos Iniciales

Manipulación de Datos y Modelos

Interactivo Consola Tinker

# Entrar al entorno de pruebas (REPL)

$ php artisan tinker

Estructura Creación de Modelos

# Crear modelo para Entradas

$ php artisan make:model Entrada

# Crear modelo para Comentarios

$ php artisan make:model Comentario

🌱 Semillas (Seeds)

Los Seeders sirven para poblar la base de datos con información falsa o de prueba automáticamente.

1. Generar archivo make:seeder
php artisan make:seeder EntradasTableSeeder
2. Sembrar datos db:seed
php artisan db:seed
