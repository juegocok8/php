Paso 3: Configuración de Pruebas

Eligiendo tu "Juez" de Código

Laravel te pregunta: "¿Qué framework de pruebas prefieres?".
Esto define qué herramienta usarás para escribir pruebas automatizadas (código que revisa que tu aplicación funcione bien).

Which testing framework do you prefer? [Pest]:
  • [0] Pest (Por defecto)
  • [1] PHPUnit
> _
Moderno

0. Pest

Es la nueva estrella en el mundo de Laravel. Se enfoca en la simplicidad y elegancia.

it('has a home page', function () {
  get('/').assertStatus(200);
});
  • ✅ Menos código: Escribes mucho menos para hacer lo mismo.
  • ✅ Legible: Se lee casi como inglés ("it has a home page").
Clásico

1. PHPUnit

Es el estándar de la industria desde hace años. Es robusto, pero requiere escribir más código (clases y métodos).

public function test_home_page() {
  $this->get('/')->assertStatus(200);
}
  • 🔹 Estándar: La mayoría de tutoriales antiguos lo usan.
  • 🔹 Verbosidad: Requiere crear clases y métodos completos.

¿Qué debo hacer?

Si estás empezando hoy, Pest es la recomendación oficial de Laravel por su facilidad de uso.

Presiona ENTER (Elige Pest)

* Nota: Si eliges Pest, por debajo también usa PHPUnit, así que obtienes lo mejor de los dos mundos.
