Cambiar Directorio

Significa "Change Directory". Antes de ejecutar nada, debes entrar a la carpeta que Laravel acaba de crear.
Error común: Intentar ejecutar artisan sin haber entrado a la carpeta del proyecto.

php artisan serve

Iniciar Servidor

Este comando arranca un servidor web ligero de PHP. Convierte tu carpeta de archivos en un sitio web real accesible a través de un puerto (normalmente el 8000).
