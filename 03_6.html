Diccionario de Tablas Estándar

Laravel 11 / 12 Core

users

Es la tabla principal de la aplicación. Almacena la información de registro de los usuarios.

id name email password

password_reset_tokens

Tabla de seguridad temporal. Cuando un usuario olvida su contraseña, Laravel genera un "token" (código secreto) y lo guarda aquí para verificar que el enlace de recuperación enviado por correo es válido.

sessions

En versiones modernas de Laravel, las sesiones se guardan por defecto en la base de datos en lugar de archivos. Esta tabla rastrea qué usuarios están logueados, su dirección IP y su última actividad.

migrations

¡Muy Importante! Esta es una tabla interna del sistema (Meta-data). Laravel la usa como un "libro de historial" para saber qué cambios ya se han aplicado a tu base de datos y cuáles faltan. Nunca debes borrarla manualmente.

cache / failed_jobs

Dependiendo de tu configuración, también se crearán estas tablas. cache guarda datos temporales para que la app sea rápida, y failed_jobs registra tareas en segundo plano que fallaron (como un email que no se pudo enviar).
