Módulo: Automatización Masiva de Datos

Estructura y Poblado con Factories

Implementación técnica para la generación de datos masivos relacionados entre las entidades Entradas y Comentarios mediante el uso de Model Factories y Faker.

1

Modelos, Migraciones y Factories

Ejecute los comandos Artisan para generar la tripleta estructural básica de cada entidad:

php artisan make:model Entrada -mf
php artisan make:model Comentario -mf
1.2

Comandos de Creación de factory [opcional]

Si no usaste la bandera -f al crear el modelo, puedes crear las factories individualmente con estos comandos:

php artisan make:factory EntradaFactory
php artisan make:factory ComentarioFactory

Configuración del Molde: EntradaFactory

Ubicación: database/factories/EntradaFactory.php

<?php

namespace Database\Factories;

use Illuminate\Database\Eloquent\Factories\Factory;

/**
 * @extends \Illuminate\Database\Eloquent\Factories\Factory<\App\Models\Entrada>
 */
class EntradaFactory extends Factory
{
  /**
   * Define the model's default state.
   *
   * @return array<string, mixed>
   */
  public function definition(): array
  {
    return [
      'titulo' => fake()->sentence(),
      'contenido' => fake()->paragraphs(3, true),
    ];
  }
}
3.2

Configuración del Molde: ComentarioFactory

Ubicación: database/factories/ComentarioFactory.php

<?php

namespace Database\Factories;
namespace use App\Models\Entrada;
use Illuminate\Database\Eloquent\Factories\Factory;

/**
 * @extends \Illuminate\Database\Eloquent\Factories\Factory<\App\Models\Comentario>
 */
class ComentarioFactory extends Factory
{
  /**
   * Define the model's default state.
   */
  public function definition(): array
  {
    return [
      'mensaje' => fake()->realText(150), // Texto de ~150 caracteres
      'entrada_id' => Entrada::factory(), // Crea la relación automática
    ];
  }
}
4

Activar el Trait HasFactory

Añada el trait HasFactory en cada uno de sus modelos:

app/Models/Entrada.php
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use App\Models\Comentario;

class Entrada extends Model {
  use HasFactory; // Importante

  protected $fillable = ['titulo', 'contenido'];

  public function comentarios()
  {
    return $this->hasMany( Comentario::class);
  }
}
app/Models/Comentario.php
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
class Comentario extends Model {
  use HasFactory;
}
4

Cómo ejecutar las Factories

Para que las factories funcionen, debemos llamarlas dentro del método run() en el archivo maestro de semillas.

database/seeders/DatabaseSeeder.php
public function run(): void
{
  // Generamos 100 entradas y cada una con 5 comentarios
  \App\Models\Entrada::factory(100)
    ->hasComentarios(5)
    ->create();
}
!

Ejecución en Terminal:

# Opción 1: Borrar todo y volver a sembrar (Recomendado)
php artisan migrate:fresh --seed

# Opción 2: Solo ejecutar los seeders
php artisan db:seed

¿Qué sucede internamente? Laravel lee la factory de Entrada 100 veces, genera los datos ficticios con Faker, y por cada entrada creada, dispara la factory de Comentario 5 veces vinculando automáticamente el entrada_id.

Verificación Final

Para estar 100% seguros de que los datos están ahí, usa Tinker, la consola interactiva de Laravel:

$ php artisan tinker
>>> App\Models\Entrada::count()
=> 100 // Registros base
>>> App\Models\Comentario::count()
=> 500 // Registros relacionados

¿Lograste ver los 100 registros en la consola?
