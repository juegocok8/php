Instalación de
Raspberry Pi OS
con Raspberry Pi Imager

Procedimiento guiado paso a paso para la preparación, selección de sistema operativo optimizado para Raspberry Pi 3 (1 GB RAM) y preconfiguración automatizada de red y credenciales.

12
Pasos
~15min
Duración
RPi 3
Hardware

Resultados de Aprendizaje

Competencias que desarrollarás durante esta práctica

01

Prepara el medio de almacenamiento extraíble (microSD/USB) utilizando Raspberry Pi Imager, verificando el formato de particionado y la integridad física del soporte para garantizar un medio de arranque libre de errores.

02

Selecciona la variante óptima de Raspberry Pi OS analizando las especificaciones técnicas del hardware (arquitectura de la CPU, 1 GB de memoria RAM) y las necesidades operativas del proyecto.

03

Aplica parámetros de preconfiguración automatizada (OS Customization) mediante la interfaz de Raspberry Pi Imager, definiendo credenciales de usuario, zona horaria y conectividad inalámbrica.

Secuencia de Instalación

01
Paso 1

Raspberry Pi Imager

Paso 1

Descargar e instalar Raspberry Pi Imager

Visita el sitio oficial en raspberrypi.com/software y descarga el instalador correspondiente para Windows.

02
Paso 2

Ejecutar la aplicación

Paso 2

Ejecutar Raspberry Pi Imager

Inicia la aplicación recién instalada desde el menú de inicio de Windows o acceso directo del escritorio.

03
Paso 3

Seleccionar modelo

Paso 3

Seleccionar el modelo de Raspberry Pi

En la sección Device, selecciona Raspberry Pi 3 (compatible con Model A+ / B / B+ y Compute Module 3) y haz clic en Next.

04
Paso 4

Elegir SO

Paso 4

Seleccionar la versión del Sistema Operativo

Para una Raspberry Pi 3 con 1 GB de RAM, selecciona Raspberry Pi OS (Legacy, 32-bit) con entorno de escritorio. Esta distribución optimiza el consumo de memoria RAM y garantiza compatibilidad con Arduino IDE.

05
Paso 5

Seleccionar storage

Paso 5

Seleccionar el medio de almacenamiento

Conecta tu tarjeta microSD o unidad USB y selecciónala en el listado de unidades disponibles (por ejemplo: Generic Mass-Storage USB Device 14.4 GB). Presiona Next.

06
Paso 6

Hostname

Paso 6

Asignar nombre al dispositivo (Hostname)

En la pestaña Customisation > Hostname, ingresa el identificador único para la placa en la red (ejemplo: ricardoServer).

07
Paso 7

Localización

Paso 7

Configuración regional (Localisation)

Establece la zona horaria en America/El_Salvador (Capital city: San Salvador) y define la distribución de teclado requerida (ej. us). Presiona Next.

08
Paso 8

Usuario

Paso 8

Creación de cuenta de usuario

Define el nombre de usuario local (ej. ricardo) y su contraseña de inicio de sesión. Confirma la clave y presiona Next.

09
Paso 9

Wi-Fi

Paso 9

Configuración de red Wi-Fi

En la pestaña Wi-Fi, ingresa el SSID (nombre de red) y la contraseña correspondiente para que la Raspberry Pi se vincule a la red automáticamente desde el encendido.

10
Paso 10

Confirmar

Paso 10

Revisión del resumen y confirmación

Verifica que los parámetros seleccionados coincidan en la ventana de resumen y presiona el botón WRITE. Confirma la advertencia de formateo de datos haciendo clic en I UNDERSTAND, ERASE AND WRITE.

11
Paso 11

Escritura

Paso 11

Proceso de escritura y verificación

Espera pacientemente a que la herramienta complete la descarga/escritura de los bloques de datos y el posterior análisis de verificación de integridad al 100%. No desconectes la unidad durante este proceso.

Finalización

¡Proceso completado!

Finalización exitosa

Finalización del proceso

Al mostrarse la ventana Write complete!, la unidad se habrá expulsado de manera segura de tu sistema. Haz clic en FINISH, extrae la tarjeta o USB y conéctala a la Raspberry Pi 3 para el primer arranque.

Siguiente paso

Inserta el medio en la Raspberry Pi 3, conecta alimentación y espera el primer arranque. La configuración de red y usuario se aplicará automáticamente.
