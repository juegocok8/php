Paso 4: Integración con IA

¿Tu código necesita un "Boost"?

Laravel te pregunta: "¿Quieres instalar Laravel Boost para mejorar la codificación asistida por IA?".
Veamos qué significa esto y si lo necesitas.

Do you want to install Laravel Boost to improve AI assisted coding? (yes/no) [yes]:
> _
Nuevo en v12

🤖 ¿Qué es Boost?

Es una herramienta que ayuda a los asistentes de IA (como GitHub Copilot, Cursor, o ChatGPT) a entender tu proyecto.

🧠
Contexto Inteligente: Le da a la IA el "mapa" de tu base de datos y tus rutas para que no alucine código.
📚
Documentación Local: Permite a la IA leer la documentación exacta de la versión de Laravel que tienes instalada.

🤔 ¿Qué respondo?

Opción A: [yes] (Sí)

Recomendado si usas editores modernos.

  • Si usas Cursor, VS Code con Copilot o PHPStorm con IA.
  • Quieres que la IA te ayude a escribir migraciones o controladores sin errores.
  • Es solo un paquete de desarrollo (--dev), no afecta tu producción.

Opción B: [no] (No)

Válido si prefieres lo clásico.

  • Si estás aprendiendo a escribir cada línea a mano.
  • Si tu computador es muy antiguo o lento.
  • Siempre puedes instalarlo después con composer require laravel/boost.
