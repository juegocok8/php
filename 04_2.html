1

Definir las Columnas (Editar Archivos)

📂 database/migrations/ ...create_entradas_table.php
public function up(): void
{
  Schema::create('entradas', function (Blueprint $table) {
    $table->id();
    $table->string('titulo');     $table->text('contenido');     $table->boolean('publicada')->default(true);     $table->timestamps();
  });
}
📂 database/migrations/ ...create_comentarios_table.php
public function up(): void
{
  Schema::create('comentarios', function (Blueprint $table) {
    $table->id();
    $table->foreignId('entrada_id')->constrained()->onDelete('cascade');     $table->text('mensaje');     $table->timestamps();
  });
}
Nota: constrained() conecta automáticamente con la tabla 'entradas'. onDelete('cascade') borra los comentarios si se borra la entrada.

3

Enseñar a Laravel las Relaciones

Laravel no "adivina" que una entrada tiene comentarios. Debemos escribirlo en los modelos.

App/Models/Entrada.php
class Entrada extends Model {
  protected $fillable = ['titulo', 'contenido', 'publicada'];

  public function comentarios() {
    return $this->hasMany(Comentario::class);
  }
}
App/Models/Comentario.php
class Comentario extends Model {
  protected $fillable = ['entrada_id', 'mensaje'];

  public function entrada() {
    return $this->belongsTo(Entrada::class);
  }
}
4

Insertar Datos de Prueba

A. Crear el archivo Seeder

$ php artisan make:seeder EntradasTableSeeder

B. Editar (database/seeders/EntradasTableSeeder.php)

public function run(): void {
  // Creamos una entrada
  $id = DB::table('entradas')->insertGetId([
    'titulo' => 'Mi Primer Post',
    'contenido' => 'Contenido de prueba...',
    'created_at' => now(),
  ]);

  // Le creamos un comentario a esa entrada (usando el $id)
  DB::table('comentarios')->insert([
    'entrada_id' => $id,
    'mensaje' => 'Excelente artículo',
    'created_at' => now(),
  ]);
}

C. Registrar en el Maestro y Ejecutar

En DatabaseSeeder.php agregar: $this->call(EntradasTableSeeder::class);

$ php artisan db:seed

¿Cómo sé si terminé?

Ve a tu base de datos (o usa Tinker) y deberías ver:

  • Tabla entradas con 1 fila.
  • Tabla comentarios con 1 fila vinculada a la entrada.
