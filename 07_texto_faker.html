Generación de texto con Faker (Laravel)

Faker permite generar texto falso pero realista para poblar bases de datos usando factories. A continuación se muestran los métodos más usados para generar títulos, párrafos y contenido.

sentence()
fake()-> sentence(6);

// Genera una oración corta (ideal para títulos)
words()
fake()-> words(5, true);

// Genera 5 palabras unidas por espacios
text()
fake()-> text(100);

// Texto aleatorio de hasta 100 caracteres
realText()
fake()-> realText(300);

// Texto más natural y coherente (recomendado para contenido)
paragraph()
fake()-> paragraph(3);

// Párrafo de 3 oraciones
paragraphs()
fake()-> paragraphs(3, true);

// Genera 3 párrafos unidos en un solo texto
slug()
fake()-> slug();

// Ideal para URLs amigables
Ejemplo completo en Factory
return [
  'titulo' => fake()->sentence(6),
  'contenido' => fake()->realText(300),
  'slug' => fake()->slug(),
];
