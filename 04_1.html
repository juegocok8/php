Módulo 9: Base de Datos y Eloquent

Creación de Tablas y Relaciones

Vamos a poner en práctica los comandos de tus diapositivas. Crearemos un sistema simple de Blog con dos tablas: Entradas (Posts) y Comentarios.

1

Generar la Estructura

Tabla A: Entradas

create_entradas_table

Primero, creamos el modelo y su migración correspondiente.

$ php artisan make:model Entrada -m
Schema::create('entradas', function (Blueprint $table) {
  $table->id();
  $table->string('titulo');
  $table->text('contenido');
  $table->timestamps();
});

Tabla B: Comentarios

create_comentarios_table

Los comentarios pertenecen a una entrada (Relación 1:N).

$ php artisan make:model Comentario -m
Schema::create('comentarios', function (Blueprint $table) {
  $table->id();
  $table->foreignId('entrada_id')->constrained();
  $table->text('mensaje');
  $table->timestamps();
});
Nota: Al ejecutar php artisan migrate, estas instrucciones se convierten en tablas reales en tu base de datos.
2

Poblar Datos (Seeders)

En lugar de insertar datos manualmente uno por uno, usamos Seeders para crear datos de prueba automáticamente. Esto es lo que hacía el comando make:seeder EntradasTableSeeder en tu diapositiva.

class EntradasTableSeeder extends Seeder {
  public function run() {
    DB::table('entradas')->insert([
      'titulo' => 'Mi Primera Entrada',
      'contenido' => 'Hola mundo Laravel...',
      'created_at' => now()
    ]);
  }
}

Comando de Ejecución

php artisan db:seed

Este comando busca tu archivo seeder y ejecuta la función run(), insertando los datos en la tabla.

Laboratorio: Eloquent & Tinker

Manipulación de Datos en Tiempo Real

Antes de construir formularios visuales, los desarrolladores utilizan la consola para verificar que la base de datos y los modelos funcionen correctamente. A continuación, el flujo completo.

Paso 1

Estructura (Migración)

Definimos que nuestra tabla entradas tendrá título y contenido.

Schema::create('entradas', function ($table) {
  $table->id();
  $table->string('titulo');
  $table->text('contenido');
  $table->timestamps();
});
Paso 2

Poblado (Seeder)

Usamos db:seed para insertar datos de prueba iniciales sin escribirlos a mano.

$ php artisan db:seed
INFO Seeding database.
3

Laravel Tinker: El Laboratorio

¿Qué pasa realmente cuando ejecutamos comandos en la consola?

php artisan tinker
// 1. Creamos una "instancia" vacía del modelo en memoria
>>> $entrada = new App\Models\Entrada;

¿Qué acaba de pasar?
Al ejecutar save() en Tinker, Laravel tradujo tu código PHP a una consulta SQL (INSERT INTO...) y la ejecutó en MySQL/SQLite. El resultado es que la fila apareció físicamente en la tabla.
